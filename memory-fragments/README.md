# Memory Fragments

A Python library for processing and managing memory fragments.

## Installation

```bash
pip install memory-fragments
```

## Usage

```python
from memory_fragments import MemoryFragment

# Create a memory fragment
fragment = MemoryFragment()

# Process the fragment
result = fragment.process()
```

## Development

### Setup

```bash
# Clone the repository
git clone <repository-url>
cd memory-fragments

# Install in development mode
pip install -e .[dev]
```
